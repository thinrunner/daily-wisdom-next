# Мудрость дня

Одна цитата на каждый день — на русском, английском, иврите и румынском. PWA с офлайн-режимом и превью для мессенджеров.

## Запуск

```bash
npm install
npm run dev
```

Стек: Next.js 16 (App Router), React 19. Внешних сервисов и базы данных нет.

## Цитаты

Источник — `content/quotes/*.mjs`: каждая цитата записана один раз, сразу на четырёх языках, с автором и настроением (от него зависит цвет фона).

`npm run quotes` (запускается сам перед `dev` и `build`) проверяет базу и собирает `lib/generated/quotes-<lang>.json`. Сборка падает, если:

- цитат меньше 366 — иначе они повторятся в течение года;
- есть дубликаты, пустой перевод, неизвестный автор или настроение;
- текст длиннее 180 символов.

Цитата дня выбирается по сплошному счёту дней (`номер дня % количество цитат`), поэтому одна и та же цитата возвращается не раньше чем через год. Порядок перемешан детерминированно: один автор не появляется чаще раза в 10 дней. Добавление цитат меняет порядок — «сегодняшняя» цитата после деплоя может стать другой.

## Превью ссылок

Кнопка «Поделиться» отдаёт ссылку вида `/?d=2026-11-27&lang=ru`. По ней сервер собирает метаданные и картинку `/api/og?d=…&lang=…` именно для этой цитаты; получатель, открыв ссылку, видит её же (если ей не больше недели).

## Деплой

Vercel, без настроек. Домен берётся из `VERCEL_PROJECT_PRODUCTION_URL`; свой можно задать через `NEXT_PUBLIC_BASE_URL`.
